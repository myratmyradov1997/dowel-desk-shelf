# STL files

All files are in print orientation. Quantities differ from 1 here:

| File | Print |
|---|---|
| `01-shelf/rod_clip_*` | 2 × (one variant) |
| `01-shelf/leg_inner_*` | one variant, left + right |
| `04-gridfinity/gf_plate_*_half_*` | **2 × each** (two halves form one plate) |
| `06-storage/tray_pin` | 8 × |
| `06-storage/tray_lock_pin` | 2 × |

Everything else: 1 ×. Details: [docs/printing.md](../docs/printing.md), [docs/accessories.md](../docs/accessories.md).
